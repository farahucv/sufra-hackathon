# Saudi Kitchen Explorer

Create a polished mobile-first UI/UX prototype for a Saudi food-tech hackathon concept. The product lets users discover short chef recipe reels, personalize recipes based on allergies or foods they cannot eat, suggest safe substitutions, enter ingredients they already have at home and get meal suggestions using only those ingredients, compare missing ingredient prices across local Saudi supermarkets, import a TikTok/YouTube recipe link and extract the recipe, browse traditional Saudi dishes by region, view chef profiles, read chef blogs, see recommendations, and access future academy/courses and chef chat/call features.

For the first version, prioritize these screens and flows:
1) Onboarding with dietary restrictions/allergies and disliked foods.
2) Home/Reels feed with chef videos, categories, save, like, recipe details.
3) Recipe detail with ingredients, steps, allergens, substitutions, serving adjustment, estimated local cost, and "shop missing ingredients".
4) My Pantry screen where users add ingredients they have; show meal suggestions that only use selected ingredients.
5) Grocery comparison screen for Saudi supermarkets with item availability, price comparison, total basket, and best-store summary.
6) Import Recipe screen for pasting TikTok/YouTube links, with a clear AI extraction result state.
7) Explore Saudi Cuisine screen organized by Saudi regions and traditional dishes.
8) Chef profile with bio, reels, recipes, recommendations, reviews, and future book/chat/call actions.
9) Saved recipes/profile/settings.
10) Clear future-expansion section for blogs, academy/courses, and live chef consultation.

Visual direction: premium modern food app, warm Saudi-inspired palette (sand, date brown, olive/green accents, cream), high-quality food imagery, rounded cards, elegant Arabic-friendly typography, clear iconography, lots of whitespace, modern but not childish. Make the experience suitable for a hackathon demo. Include Arabic-first RTL-ready structure with concise Arabic interface copy, and optional English labels only where useful. Use realistic sample data for Saudi dishes, chefs, and supermarket comparisons, but make it obvious this is demo data.
